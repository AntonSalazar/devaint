# Фракции, мутаторы, геном, герои, экономика

> Стартовые числа — в `07-BALANCE.md`.

## 1. Фракция

Фракция — это запись:

- `Id`, `Name`, `Color` (цвет — данные, семантики не несёт);
- `Mutators: List<Modifier>` — стартовые модификаторы, бесплатно, из бюджета
  очков при создании;
- `Genome: List<Modifier>` — модификаторы, купленные за Compute в партии;
- `Compute: int` — ресурс;
- `Controller: Human | Ai(profile)`.

**Симметрия — закон.** Правила одинаковы для всех, бот не получает
скрытых бонусов. Единственная асимметрия — состав мутаторов и генома.
Это делает баланс проверяемым: одна и та же фракция против самой себя
должна выигрывать в ~50 % авто-партий (`06-AI.md`, `07-BALANCE.md`).

## 2. Модификатор — одна структура для мутатора и генома

```
Modifier {
  Id, Name, Description
  Tags                 // ветка: stealth | economy | offense | mobility | swarm
  MutatorCost          // очки при создании фракции (0 = не доступен как мутатор)
  ComputeCost          // цена в партии (0 = не доступен как ген)
  Requires             // Id других модификаторов (дерево тегами, без графа в коде)
  // Эффекты — только числа, симуляция читает их как коэффициенты:
  PowerBonus[Os]       // +N к Power эксплойтов по ОС
  NoiseMult            // множитель шума от действий
  ComputeMult          // множитель дохода
  ExtraActionPoints    // +N очков действия героям
  ExtraCharges         // +N к максимуму зарядов каждого слота
  ExtraHeroSlots       // +N к лимиту героев
  HardenBonus          // +N к укреплению
  ScanRadiusBonus      // +N к радиусу скана
  StartingExploit      // Id эксплойта, выдаётся первому герою (только мутатор)
}
```

Итоговые коэффициенты фракции = свёртка всех её модификаторов
(множители перемножаются, бонусы складываются). Считается один раз
при изменении набора и кэшируется как `FactionStats`.

### Мутаторы (создание фракции)

Бюджет — **3 очка**. Примеры стартового пула (числа в `07-BALANCE.md`):

| Мутатор | Ветка | Цена | Эффект |
|---|---|---|---|
| Silent kernel | stealth | 2 | Шум ×0.5 |
| Miner | economy | 1 | Доход ×1.25 |
| Native: Kestrel / Bastion / Mote / Forge | offense | 1 | +1 Power по одной ОС |
| Swift | mobility | 2 | +1 очко действия |
| Hoarder | offense | 1 | +1 макс. зарядов |
| Hive | swarm | 2 | +1 слот героя |
| Zero-day cache | offense | 2 | Стартовый эксплойт T3 по случайной ОС |
| Bunker | stealth | 1 | +1 к укреплению |

Пресеты фракций из `01-WORLD.md` — это готовые наборы на 3 очка.
Бот берёт пресет или случайный набор на тот же бюджет.

### Геном (покупки в партии)

Тот же пул плюс дорогие ступени с `Requires` (Silent kernel II требует
Silent kernel). Покупка — фракционное действие, без героя и очков, только
Compute. Геном — единственная «наука», и он маленький: 10–15 записей
на релиз. Ветка читается тегом, дерево рисуется из `Requires`.

## 3. Герой — процесс

Герой — юнит фракции:

```
Hero {
  Id, FactionId, Name
  Pos: Hex                 // всегда свой узел
  ActionPoints             // сбрасывается в upkeep до максимума
  Exploits: List<ExploitSlot>   // слоты: Def + Charges
  SlotLimit                // базово 3, растёт геномом
}
```

Правила:

- **Стоит только на узле своей фракции.** Ходит только по своим узлам
  (и по линкам между своими). Захват расширяет территорию, движение —
  перемещение внутри неё.
- **Смерть.** Если узел, на котором стоит герой, отжат или ушёл
  под аудит — процесс убит, слоты потеряны. Это главная цена ошибки
  и главная цель охоты: отрезать героя от серверов и снести узел под ним.
- **Один герой на узел.** Стек запрещён; чужой герой на твоём узле
  невозможен по определению (владелец один).
- **Спавн** — фракционное действие на своём сервере за Compute; новый герой
  появляется с пустыми слотами. Лимит героев = 1 + число своих серверов
  + `ExtraHeroSlots`. Потерял сервер — лимит упал, лишние герои остаются,
  но новых не нанять.
- Нет уровней и опыта. Сила героя = его слоты + геном фракции. Всё, что
  сделало бы одного героя «прокачанным», должно быть в данных фракции,
  чтобы потеря героя была больно, но не фатально.

### Очки действия

Базово **3 в ход** (+ мутаторы/геном). Стоимость действий —
в `05-TURN-LOOP.md`. Неизрасходованные не переносятся.

## 4. Серверы — города

Сервер под твоим владением даёт:

- **доход** Compute выше остальных типов;
- **компиляцию** эксплойтов (фракционное действие, `04-EXPLOITS.md`);
- **спавн** героев;
- **пополнение зарядов** героям, стоящим на нём в начале хода (+1 заряд
  в каждый слот, до максимума);
- **+1 к лимиту героев**.

Потеря сервера = потеря всего списка. Сервер стоит защищать
и первым делом — укреплять (`04-EXPLOITS.md §Укрепление`).

## 5. Экономика Compute

- **Доход** в upkeep: сумма `Yield[Type]` по своим узлам × `ComputeMult`.
- **Расход:** компиляция эксплойтов (по тиру), геном (по записи), спавн героя
  (фикс), укрепление (за уровень).
- **Без накопительства:** нет процентов, нет лимита, но всё дорожает
  вглубь (тир эксплойта — квадратично), а мировые события обесценивают
  старые эксплойты. Сидеть на куче Compute — проигрывать темп.
- Целевой профиль: к ходу 10 — доход ~10/ход, к ходу 30 — ~40/ход.
  Проверяется авто-партиями (`07-BALANCE.md §Метрики`).

## 6. Пример хода фракции (для ощущения масштаба)

Ход 12. Доход +14 Compute (итого 31). Герой A стоит на сервере офиса:
заряды пополнились. Компилирую `Kestrel T2` за 10 — ставлю герою A.
Герой A: скан (1 ОД) — за роутером виден чужой Workstation с патчем 2.
Захват роутера `Bastion T2` (1 ОД, заряд) — есть. Переход на роутер (1 ОД).
Герой B в жилом районе: три захвата `Home` по `Kestrel T1` (3 ОД,
3 заряда) — территория +3, доход +3. Конец хода. В логе: противник
укрепил датацентр; вышел патч на Mote — мои IoT-эксплойты ослабли.
