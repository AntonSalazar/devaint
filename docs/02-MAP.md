# Карта: гексы, узлы, слои, генерация

> Стартовые числа — в `07-BALANCE.md`; здесь — правила и структура.

## 1. Гексагональная сетка

- **Ориентация:** pointy-top (вершиной вверх), ряды со сдвигом.
- **Координаты симуляции — аксиальные** `Hex(q, r)`. Шесть направлений —
  константы; расстояние — через кубические координаты. Всё по Red Blob
  Games, без самодеятельности.
- **Хранение — плоский массив** по offset-координатам «odd-r»
  (`col = q + (r - (r & 1)) / 2`, `row = r`). Конверсия аксиал ↔ offset —
  две функции, покрытые тестом round-trip. Offset-координаты нужны только
  на границе с `TileMapLayer` (`08-VISUAL-UI.md`).
- **Размер карты** зависит от числа фракций (таблица в `07-BALANCE.md §1`):
  дуэль — 26 × 20 (520 гексов), 8 фракций — 48 × 36. Во всех случаях
  ~35–45 % гексов — узлы, остальное — воздушный зазор. Плоский массив
  и текстура данных масштабируются без правок кода.

## 2. Типы узлов

| Тип | Роль | Аналог из Героев |
|---|---|---|
| `Empty` | Воздушный зазор, непроходим, не захватывается | Гора / вода |
| `Home` | Домашний ПК. Дешёвый, слабый, много | Крестьянин у дороги |
| `Workstation` | Офисная машина. Средний доход, средняя защита | Шахта |
| `Server` | «Город»: доход, компиляция эксплойтов, спавн героев, пополнение зарядов | Замок |
| `Router` | Мост между кластерами; единственный проход; сканирует дальше | Мост / гарнизон |
| `IoT` | Умные устройства: почти без защиты, почти без дохода, но их много и они рядом со всем | Дорога |
| `Controller` | Промышленный контроллер: высокая защита, высокий доход, редкие ОС | Золотая шахта |

У типа — таблица свойств (`07-BALANCE.md`): распределение ОС, базовый
`Patch`, доход Compute, радиус скана, ценность для генератора имён.

## 3. Семейства ОС

Четыре семейства (имена — плейсхолдеры, не торговые марки):

| ОС | Где живёт | Характер |
|---|---|---|
| `Kestrel` | Home, Workstation | Массовая потребительская. Много эксплойтов, быстро патчится |
| `Bastion` | Server, Router | Серверная. Мало эксплойтов, высокая базовая защита |
| `Mote` | IoT | Встроенная. Дырявая, почти не патчится |
| `Forge` | Controller | Промышленная. Редкие дорогие эксплойты, патчей почти нет |

Эксплойт бьёт только по своей ОС (`04-EXPLOITS.md`). Разнообразие ОС
на карте = необходимость держать разные эксплойты = решения при компиляции.

## 4. Слои карты

Каждый слой — плоский массив `width × height`, без логики. Новый слой =
новая механика без правок симуляции.

| Слой | Тип | Смысл | Кто меняет |
|---|---|---|---|
| `Type` | `NodeType` | Тип узла | Генератор |
| `Os` | `Os` | Семейство ОС | Генератор |
| `Patch` | `int 0..5` | Защита | Генератор, укрепление, патч-события |
| `Owner` | `int` (-1 нейтрал) | Владелец | Захват, аудит |
| `Noise` | `float 0..1` | Накопленный шум | Действия героев, затухание в upkeep |
| `KnownBy[f]` | `bool` на фракцию | Снят ли туман для фракции f | Скан, захват, шум |
| `Name` | `string` | Имя узла для UI/лога | Генератор |

Отдельно от слоёв — `Links: List<Link>` (см. §6).

## 5. Кластеры и роутеры

- Карта состоит из **кластеров** — компактных пятен узлов одного профиля:
  жилой район (Home + IoT, Kestrel/Mote), офис (Workstation + Server,
  Kestrel/Bastion), датацентр (Server, Bastion), завод (Controller + IoT,
  Forge/Mote).
- Между кластерами — воздушный зазор. Единственный наземный проход —
  **коридор из роутеров** (1–3 гекса `Router`). Роутер принадлежит
  коридору, а не кластеру.
- Следствие: герой, стоящий только на своих узлах (`03-FACTIONS-HEROES.md`),
  выходит из кластера только через захваченный роутер. Отжали роутер —
  всё за ним отрезано, герои там заперты.
- Роутер сканирует радиусом 3 вместо 2 — «башня».

## 6. Дальние линки

`Link(A, B, Kind)` — двусторонняя связь между не соседними гексами.
Для всех правил концы линка считаются **соседями**: по ним можно
захватывать, двигаться и сканировать так же, как по шести соседним гексам.

| Kind | Между чем | Зачем |
|---|---|---|
| `Backbone` | Роутер ↔ роутер дальних кластеров | Быстрый прорыв через полкарты |
| `Vpn` | Офис ↔ офис | Обход роутера |
| `Sneakernet` | Home ↔ Workstation («флешка домой») | Прыжок из жилого района прямо в офис |

Линки видны только если снят туман хотя бы с одного конца. Мировое событие
может линк порезать (`05-TURN-LOOP.md`), но не навсегда.

## 7. Туман войны

- У каждой фракции — свой слой `KnownBy`; у союзников зрение общее
  (`SharedVision`, параметр правил, по умолчанию вкл): скан и захват
  союзника снимают туман и тебе. Неизвестный гекс рисуется
  как помехи; известный, но не наблюдаемый — сохраняет последнее
  известное состояние (`Owner`, `Patch` на момент скана).
- Снимается:
  - **захватом** — узел и все его соседи (включая концы линков);
  - **сканом** — радиус 2 от героя, 3 от роутера (`05-TURN-LOOP.md §Действия`);
  - **шумом** — гекс с `Noise ≥ порог` виден всем фракциям всегда
    («аномалия трафика»). Это и есть цена громкой игры.
- Нет вечного зрения: захваченные узлы наблюдаются, всё остальное —
  память. Противник может укрепить узел у тебя за спиной, и ты узнаешь
  об этом при попытке захвата (UI показывает «данные устарели»).

## 8. Генерация (от сида)

Всё детерминировано от `seed`: одинаковый сид — одинаковая карта на любой
машине. Порядок шагов:

1. **Пустая карта** заданного размера, всё `Empty`.
2. **Центры кластеров.** Разбросать K центров с минимальной дистанцией
   (Poisson-подобно: пробы, отбраковка ближе `minDist`). K ≈ 2 × число
   фракций + 3 (дуэль — 7).
3. **Профили кластеров.** По одному жилому на фракцию (это старты),
   офисов — столько же, датацентр — один на каждые 2–3 фракции, завод —
   один на 4, остальное — случайно. Датацентры — в точках, максимально
   удалённых от всех стартов (спорные).
4. **Заливка.** Каждый кластер — BFS от центра радиусом `r` (2–3) с шансом
   «дырки», типы и ОС — по распределению профиля, `Patch` — базовый по типу
   ± 1 случайно. Сервер — в центре кластера (не для жилого).
5. **Коридоры.** Построить минимальное остовное дерево по центрам + 1–2
   лишних ребра (циклы = обходные пути). Для каждого ребра — кратчайший
   гекс-путь между границами кластеров, застроить его `Router`
   (только участок через зазор; длинный коридор → роутеры через один,
   между ними `IoT`).
6. **Линки.** 1 `Backbone` между самыми дальними роутерами, 1–2 `Vpn`,
   1–2 `Sneakernet`.
7. **Старты.** N жилых кластеров по farthest-point: первый — случайный,
   каждый следующий — максимально удалённый от уже выбранных. Союзники
   по возможности рядом (опция `AlliesAdjacent`, по умолчанию вкл —
   как в Героях, где команда стартует в одном углу). Стартовый узел —
   `Home` в центре кластера, сразу с владельцем и героем.
8. **Имена.** Генератор имён по профилю кластера.
9. **Валидация.** Граф узлов связен; от каждого старта достижим ближайший
   датацентр не дальше, чем от любого другого старта, с допуском 2 гекса;
   попарное расстояние между стартами ≥ `minStartDist`; иначе — следующий
   сид (`seed + 1`), с логом.

Опция **зеркальной карты** для дуэли (для 4 — четверти, для остальных
недоступна): генерируется половина, отражается
по длинной оси, роутеры-коридоры сшиваются по центру. Честнее, скучнее;
по умолчанию выключена, включается настройкой.

## 9. Сценарии (после прототипа)

Сценарий = `seed` + список правок слоёв (точечные `Set(hex, layer, value)`)
+ свой набор мировых событий и реплик + условия победы. Никакого отдельного
формата карты: сценарий — это патч поверх генератора, и он тоже данные.
