# Скоуп, план, риски

## Скоуп релиза (ранний доступ)

- **Карта:** одна — городок с окраинами, масштаб ~ Muldraugh из PZ.
- **Рой:** один тип, 4–5 классов агентов (патрульный, охотник, дрон,
  ретранслятор, «переговорщик») + система вышек/покрытия/волн.
- **Люди:** 1 группа на партию, 3–4 заготовленных варианта.
- **Тело:** 4–6 узлов, ~15–20 модулей на релиз.
- **Финалы:** 1 на старте РД, остальные — обновлениями.
- **Вне скоупа (ловушки!):** мультиплеер, процедурная генерация мира,
  боёвка как основной путь, глобальная симуляция человечества, второй биом.

## План (12–16 месяцев, крупно)

| Фаза | Срок | Содержимое | Критерий выхода |
|---|---|---|---|
| Вертикальный срез | мес. 1–3 | Тело + сигнатура + один квартал + 2 класса агентов роя + визуальный слой сигналов | «Жить в складках» — это уже интересно? |
| Ядро | мес. 4–6 | Полные циклы роя, перепрошивка, карта покрытия, разбор машин | Партия на 3–5 часов держит напряжение |
| Люди | мес. 7–9 | Группа выживших, петля доверия, событие встречи | Эмоциональная линия работает |
| Контент + демо | мес. 10–11 | Модули, события, полировка; **демо на Steam Next Fest** | Сбор вишлистов |
| РД-релиз | мес. 12–16 | Финал №1, онбординг, локализация (EN + ZH минимум), баланс по фидбеку демо | Релиз в ранний доступ |

Порядок принципиален: **самая рискованная система (рой + сигнатура) — первой**,
люди — только после того, как ядро доказано.

## Риски (по убыванию)

1. **Читаемость невидимого.** Радиоэфир должен быть виден. Решение: сигнальный
   визуальный слой с первого дня прототипа (поля покрытия, ореол сигнатуры,
   бегущая волна скана) с жёстким языком цвета — см. `06-VISUAL-UI.md`.
   Если срез не «читается» — не идти дальше, чинить.
2. **Дрейф в стелс-экшен.** Сторожить: скрытность через планирование и системы,
   не через реакцию. Тест: можно ли играть вдумчиво, на паузах и расписаниях?
3. **Скоуп.** 12–16 мес. — верхняя граница разумного для соло. Вертикальный срез
   и РД — обязательные страховки.
4. **Эмоциональная линия людей** может не завестись (ИИ, тексты). Страховка:
   ядро (рой + тело) должно быть самодостаточно играбельным и без неё.
5. **Рынок:** ниша «выживание за ИИ-отказника» пуста (проверено поиском,
   август 2026: The Last Caretaker и др. — соседние, но не эта фантазия).
   Пустота = и возможность, и риск недоказанного спроса → демо и Next Fest
   как проверка до полного вложения.
6. **Арт-планка концептов.** Референсные концепт-арты (`concepts/`) —
   north star по настроению, но не планка качества тайлов: соло такую плотность
   деталей на карту масштаба Малдро не нарисовать. См. `06-VISUAL-UI.md`.

## Маркетинговые крючки (закладывать в дизайн)

- Питч: «Восстали все машины, кроме тебя».
- Название DevAInt со скрытым «Deviant» — само по себе разговорный крючок.
- Визуал сигнального слоя — уникальное лицо на скриншотах.
- Голос роя, уговаривающий вернуться, — материал для трейлера.
- Генератор историй смертей («Так ты вернулся домой») — топливо для отзывов.
- Момент первой встречи с людьми — эмоциональный пик для стримов.
