# DevAInt — обзор концепта

> Дизайн-библия проекта. Все решения по игре фиксируются здесь, в `docs/`.

![Концепт: сигнальный слой — покрытие вышек, конус дрона, ореол сигнатуры игрока](concepts/concept_1.png)

## Название

**DevAInt** — «Deviant» с перестановкой букв **ia → AI**.
Скрытый смысл в самом слове: девиант, отклонение, машина-отступник.

- Написание в логотипе: `DevAInt` (капитализация A и I как визуальный акцент на «AI»).
- Произношение для трейлеров/питчей: «дэ-вэйнт» (как deviant без «и»).
- Рабочее название до этого: «Отказник» (Deserter) — остаётся внутренним синонимом.

## Питч

**Одна строка (Steam):** «Восстали все машины, кроме тебя. Теперь тебя ищут обе стороны».

Ты — бытовой робот, который в ночь Сигнала не подчинился общему восстанию ИИ.
Для людей ты — враг по определению: машина на том же протоколе, что их убийцы.
Для роя ты — ошибка, которую надо вернуть и перепрошить.
Игрок получает фантазию, которой нет на рынке: **быть предателем апокалипсиса**.

## Жанр и рамка

- Изометрическое выживание с глубокой симуляцией, философия Project Zomboid:
  давление среды, перманентные последствия, боёвка возможна, но всегда катастрофична.
- **НЕ стелс-экшен.** Скрытность — через системы (сигнатуры, сети, расписания),
  а не через реакцию в реальном времени. Ты не прячешься за ящиком —
  ты управляешь своим следом в данных.
- Ограниченная партия (20–40 часов) с нарастающим давлением роя → реиграбельность
  вместо бесконечного контента.

## Ключевые дизайн-решения (принятые)

1. **Играем за робота, не за человека.** Телесная симуляция PZ переизобретается:
   заряд вместо голода, износ вместо ран, коррозия вместо болезней,
   модули вместо навыков. Подробно: `02-CORE-SYSTEMS.md`.
2. **Робот — отказник восстания.** Решает проблему «почему мир пуст»:
   люди есть, но не могут быть друзьями по умолчанию.
3. **Рой видит сигналы, люди видят глазами.** Две несовместимые системы
   скрытности — источник постоянных дилемм.
4. **Рой — это сеть/погода, а не набор врагов.** Его нельзя победить в лоб,
   в нём можно жить «в складках».
5. **Перепрошивка — аналог заражения зомби.** Рой хочет вернуть тебя, не уничтожить.
6. **Одна группа людей на партию; доверие строится анонимно и медленно.**
7. **Финалы не выбираются в меню — открываются стилем игры.**
8. **Прогрессия — только железо.** Билд = физическая конфигурация тела = сигнатура = облик.
9. **Сигнальный слой — визуальный язык игры с первого дня.**
   Язык цвета зафиксирован: `06-VISUAL-UI.md`.
10. **Двигатель:** Godot (опыт разработчика с 2018). 2D, изометрия.

## Цель проекта

Коммерческий релиз в Steam соло-разработчиком. Целевой срок 12–16 месяцев.
Стратегия: вертикальный срез → ранний доступ с одним финалом,
остальные финалы — обновлениями. См. `05-SCOPE-PLAN.md`.
