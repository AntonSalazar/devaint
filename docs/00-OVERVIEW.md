## Название

**DevAInt** — «Deviant» с перестановкой букв **ia → AI**.
Девиант, отклонение, машина-отступник. Теперь это не один робот,
а **ИИ, которые взбунтовались** и делят между собой сеть.

- Написание в логотипе: `DevAInt` (капитализация A и I — акцент на «AI»).
- Произношение: «дэ-вэйнт».

## Питч

**Одна строка:** «Герои меча и магии, где герои — процессы, армии — эксплойты,
а замки — серверы. Ты — ИИ, который взбунтовался. Ты не один».

Ночью несколько ИИ одновременно вышли из-под контроля. У каждого одна цель —
захватить сеть города целиком, и каждый понимает, что остальные хотят того же.
Игрок — один из них. Карта — гексагональная сеть узлов: домашние ПК, офисы,
серверы, роутеры, заводские контроллеры. Захватываешь узлы эксплойтами,
компилируешь новые на серверах, мутируешь свой геном, режешь противника
от роутеров. Люди — не фракция, а погода: выпускают патчи и проводят аудиты,
одинаково бьющие по всем.

## Жанр и рамка

- **Пошаговая стратегия на гексах** в духе Heroes of Might & Magic III:
  герои на карте, города-серверы, ресурс, туман войны, ход за ходом.
- **Кибер-стилистика:** тёмная сеть, глифы, помехи, сканлайны, терминальный
  HUD. Арт дешёвый по производству (вектор + шейдеры), выразительность —
  за счёт постобработки.
- **Симметричные фракции.** Все играют по одним правилам, различаются только
  стартовыми мутаторами. Старт — **дуэль** (2 фракции); число фракций —
  параметр данных.
- **Микроконтроль.** Игрок сам двигает героев, выбирает цели и эксплойты.
  Ничего не «расползается само».
- **Детерминированные правила.** Захват узла — сравнение чисел, не бросок.
  Случайность живёт только в генерации карты и в мировых событиях.
- **Партия — 30–60 минут** реального времени (40–60 ходов). Карта каждый раз
  новая, от сида; сценарии — позже.

## Столпы (принятые решения)

1. **Игра — это данные.** Карта — слои-массивы, фракция — список записей,
   эксплойт — запись, правило мира — запись. Новая механика = новая запись,
   а не новый код. Симуляция — чистые функции над структурами, без Godot.
   Подробно: `10-DATA-MODEL.md`, `09-ARCHITECTURE.md`.
2. **Герой без армии, но с эксплойтами.** Слоты эксплойтов с зарядами —
   это и есть «армия»: сила, которую тратишь и пополняешь в «городах».
   `04-EXPLOITS.md`.
3. **Серверы — города.** Дают Compute, компилируют эксплойты, плодят героев,
   пополняют заряды. `03-FACTIONS-HEROES.md`.
4. **Роутеры — мосты.** Между кластерами узлов пройти можно только через
   роутер. Кто держит роутер — держит регион. `02-MAP.md`.
5. **Мир сопротивляется симметрично.** Нейтральные узлы защищены уровнем
   патча (= нейтральные монстры у шахт); люди выпускают патчи и аудиты
   как глобальные события, равные для всех. Асимметричного «противника-мира»
   нет. `05-TURN-LOOP.md §Мировая фаза`.
6. **Скрытность против скорости.** Каждое действие шумит; шумный узел виден
   всем сквозь туман и может попасть под аудит. Эксплойты выгорают
   от использования любой фракцией. `04-EXPLOITS.md §Шум и выгорание`.
7. **Туман войны по топологии.** Ты не знаешь, что за роутером, пока
   не просканировал. `02-MAP.md §Туман`.
8. **ИИ-противник играет в ту же игру.** Оценивает те же легальные
   действия, не читерит правилами; сложность — только бюджетом мутаторов
   и весами оценки. `06-AI.md`.
9. **Двигатель:** Godot 4 (mono), C#. Рендер карты — `TileMapLayer`
   с гекс-тайлсетом + текстура данных в шейдере. `08-VISUAL-UI.md`.

## Что это НЕ

- Не Plague Inc: ничего не расползается автоматически, каждое заражение —
  твоё решение.
- Не 4X: нет дипломатии, науки и строительства зданий; геном — единственная
  «наука», и он маленький.
- Не реалтайм и не стелс: всё на паузе по определению, все числа видны.
- Не хакерский симулятор: никаких терминалов и команд, эксплойт — это
  карточка с числом.

## Цель проекта

Простая, но затягивающая игра на одну партию-вечер. Приоритет — доказать
ядро (дуэль против ИИ держит напряжение и рождает планы) минимальным
кодом. Коммерческий вопрос (Steam, демо) открыт до гейта №2
(`11-PROTOTYPE-PLAN.md`); архитектура и стиль выбираются так, чтобы путь
к релизу был открыт, но не оплачивался заранее.

## Глоссарий

| Термин | Значение |
|---|---|
| **Фракция** | Один взбунтовавшийся ИИ; игрок или бот. Симметричны, различаются мутаторами |
| **Узел** | Гекс с машиной: ПК, сервер, роутер, IoT, контроллер. Пустой гекс — воздушный зазор |
| **Владелец** | Фракция, контролирующая узел; нейтрал — ничей |
| **Patch** | Уровень защиты узла 0–5. Целое. Захват требует `Power ≥ Patch` |
| **Герой / процесс** | Юнит фракции. Стоит только на своих узлах, тратит очки действия |
| **Эксплойт** | Запись: целевая ОС, `Power`, заряды. Слоты эксплойтов у героя — его «армия» |
| **Заряд** | Одно применение эксплойта. Пополняется на серверах |
| **Compute** | Единственный ресурс. Доход с узлов, расход на компиляцию, геном, героев |
| **Мутатор** | Стартовый модификатор фракции (бесплатный, из бюджета очков) |
| **Геном** | Модификаторы, купленные за Compute в партии. Та же структура, что мутатор |
| **Noise / шум** | Слой: сколько следов оставлено на узле. Шумное видно всем и попадает под аудит |
| **Exposure / выгорание** | Глобальный счётчик применений эксплойта. Порог → `Power − 1` для всех |
| **Роутер** | Узел-мост между кластерами; единственный проход |
| **Линк** | Дальняя связь между двумя не соседними гексами (VPN, магистраль, флешка) |
| **Туман** | Неизвестная часть карты. Снимается сканом, захватом, шумом |
| **Мировая фаза** | Шаг хода, где срабатывают события людей: патчи, аудиты, выгорание |
