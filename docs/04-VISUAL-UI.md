# Визуальный язык, экраны, HUD

> Правило проекта: **ни одного нарисованного руками спрайта.** Всё, что
> видно на экране, — геометрия, текст, шейдер или данные.

> Концепт-кадры в `concepts/` — SVG-мокапы, сгенерированные скриптом
> `concepts/gen_frames.py`: они задают композицию и язык цвета, не
> арт-планку. Правятся числа в скрипте, не пиксели.

## 1. Стиль: «кибер», не «неон»

- **Тёмная сеть.** Фон почти чёрный, узлы — глифы на гексах, владение —
  заливка низкой яркости с яркой кромкой.
- **Помехи как язык.** Туман — статический шум (шейдер), сквозь который
  читается только силуэт гекса. Шумный узел дрожит (джиттер +
  хроматическая аберрация). Мировое событие — короткий глитч экрана.
- **Терминальный HUD.** Моноширинный шрифт, рамки-скобки, значения
  цифрами. Никаких иконок-картинок там, где хватает глифа.
- **Рассвет виден.** Фон медленно светлеет от чёрного к серо-синему
  по мере приближения `DawnTurn`. Игрок чувствует таймер без цифры.
- **Постобработка** — единственный дорогой на вид элемент: сканлайны,
  лёгкая виньетка. Делается один раз, работает на всех экранах,
  отключается в настройках.

## 2. Язык цвета

| Что | Цвет |
|---|---|
| Свой узел | Один акцентный цвет игры (cyan по умолчанию, выбор — после релиза) |
| Нейтральный узел | Холодный серо-синий |
| Пустой гекс | Почти фон, без кромки |
| Туман | Статический шум, монохром |
| Шум узла | Красноватое дрожание кромки, интенсивность = `Noise`; выше порога аудита — мигание |
| Цель забега | Датацентр отмечен отдельным маркером всегда, даже под туманом |
| Линки | Пунктир; отключённый — серый разорванный |
| Доступная цель | Подсветка кромки акцентом; недоступная — красный крест при наведении с причиной |
| ОС | Цвет глифа: 4 оттенка, те же в панели слотов |

## 3. Гекс и глифы

- Pointy-top, радиус гекса ~36 px при зуме 1×; карта 18 × 14 целиком
  влезает в 1280 × 720 без скролла. Зум и скролл не нужны — один экран.
- Глиф типа узла — символ моноширинного шрифта в центре гекса, 1 цвет:
  `Home` ▭, `Workstation` ▤, `Server` ▦, `Router` ◈, `IoT` ·,
  `Controller` ⚙. Если шрифт не тянет — процедурный значок из 2–4
  линий, рисуется кодом.
- `Patch` — цифра в углу гекса (только известный узел).
- Daemon — кольцо на узле с «дыханием» (шейдер или твин масштаба).
  ОД — точки под кольцом.

## 4. Рендер

Прототип — **`_Draw()` на одном `Node2D`**: гексы, глифы, линки, кольцо
daemon'а. Перерисовка — по событию изменения состояния, не каждый кадр.
Для ~250 гексов и пошаговой игры это дёшево, целиком в коде и без
тайлсета в редакторе. Поверх — `CanvasLayer` с `ColorRect` и одним
шейдером: сканлайны, виньетка, глитч по событию, туман-помехи на
неизвестных гексах (маска передаётся текстурой W × H).

Если дрожание шума по гексу окажется дорогим в `_Draw` — второй вариант:
текстура данных W × H (R = Owner, G = Patch, B = Noise, A = Known)
и шейдер на весь слой карты. Решать на третьем уикенде, не раньше.

## 5. Экраны

### Меню

Заголовок, четыре строки: «Играть», «Ежедневный забег» (после
прототипа), «Настройки», «Выход». Фон — та же карта с шумом.

### Старт забега

Сид (случайный, редактируемый), список мутаторов с очками и бюджетом
3, кнопка «В сеть». Всё текстом и рамками.

### Забег

| Зона | Содержимое |
|---|---|
| **Верх** | Ход, «до рассвета: N», Compute (+доход/ход), индикатор ближайшей патч-волны |
| **Центр** | Карта целиком |
| **Низ** | Полоса daemon'а: ОД точками, три слота (ОС цветом, Power, заряды), кнопки Scan / Lurk / End Turn |
| **Право** | Панель узла под курсором: имя, тип, ОС, Patch, шум; для чужого — разбор захвата по каждому слоту («нужно 3, есть 2»); для своего сервера под daemon'ом — список компиляции с ценами |
| **Лево** | Лог событий с номерами ходов, последние 8 строк |

Клик по узлу: свой — `Move`, чужой — `Exploit` лучшим подходящим слотом
(или выбранным). Правый клик — снять выбор. Наведение показывает,
что будет, до клика.

### Итог

«Датацентр захвачен» / «Вычищен аудитом» / «Рассвет». Ход, узлов, счёт.
Сид, чтобы повторить. Кнопки «Ещё раз» и «В меню».

## 6. Читаемость (тест скриншота)

Кадр забега **без HUD** обязан отвечать: где я, что моё, куда можно,
где шумно, где цель, сколько осталось ночи. Проверять на `just shot`
со второго уикенда. Не читается — чинить рендер, а не добавлять подписи.

## 7. Отклик

- Захват: кромка «прожигается» акцентом за 0.3 с.
- Аудит: узел вспыхивает белым и «вымывается» в нейтральный.
- Патч-волна: волна по гексам нужной ОС от края карты.
- Смерть daemon'а: кольцо рассыпается в помехи, экран глитчит.
- Мировое событие: глитч 0.2 с + строка в логе.
- Звук — после гейта прототипа: события шины уже есть, звук — подписчик.

## 8. Steam-материалы

Капсулы и скриншоты снимаются из игры с теми же шейдерами: кадр карты
крупным планом с шумом и глитчем — это и есть обложка. Трейлер —
30 секунд забега с ускорением, без озвучки. Никакого арта извне.
